# **App Name**: SulzaX Digital Hub

## Core Features:

- Service Navigator: Interactive service selector tool to guide users to the best-suited services.
- AI Solution Advisor: AI-powered IT solution advisor tool. This tool takes the user's specifications, considers data in the SulzaX project portfolio, and suggests suitable IT solutions using generative AI, outputting an estimated budget for each solution.
- Project Showcase: Dynamic project filtering to showcase SulzaX's expertise across industries and services.
- Lead Capture Integration: Integration with a marketing automation tool for lead capturing.
- Smart Contact Form: Implement contact form with smart field detection and conditional logic to route inquiries effectively.

## Style Guidelines:

- Primary color: SulzaX Blue (#2C3E50) to convey trust and reliability.
- Background color: Light Gray (#F5F5F5), a desaturated near-white shade of SulzaX Blue, to provide a clean, modern backdrop that ensures content readability while maintaining brand consistency.
- Accent color: Teal (#1ABC9C) to highlight success states and important information.
- Body font: 'Open Sans', sans-serif, for readability.
- Headline font: 'Poppins', sans-serif, for modern, crisp headlines.
- Use consistent and professional icons to visually represent services and solutions.
- Subtle animations and transitions using Framer Motion to enhance user experience.
